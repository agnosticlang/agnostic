title: Agnostic

Agnostic — статически типизированный императивный язык. Эталонная реализация — компилятор на C++20 с тремя бэкендами кодогенерации: нативный машинный код через C++ API LLVM (`llvm`), байткод для Novaria Virtual Machine (`nvm`) и заглушка для libgccjit (`gcc`, не реализован).

В языке есть функции, функции как значения и замыкания, захватывающие переменные по ссылке, структуры с методами без наследования и без таблиц виртуальных методов, и блоки `comptime`, выбирающие код на этапе компиляции в зависимости от целевой ОС, архитектуры или режима памяти. Дженериков и сопоставления с образцом (pattern matching) нет. Что вместо них покрывает система типов, см. в разделе [Типы](/ru/types/).

Исполняемые файлы, собранные бэкендом `llvm`, не линкуются с libc. Они обращаются к ядру Linux через сырые системные вызовы и выбирают стратегию управления памятью на этапе сборки: автоматический подсчёт ссылок (`arc`, по умолчанию), ручное выделение без автоматического освобождения (`manual`), или региональное выделение на каждый вызов функции (`orc`). Подробности — в разделе [Инструментарий](/ru/toolchain/).
