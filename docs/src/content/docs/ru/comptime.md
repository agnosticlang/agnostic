---
title: Comptime-блоки
description: Условия времени компиляции по целевой ОС, архитектуре и режиму памяти.
---

Блок `comptime` вычисляет своё условие на этапе компиляции и оставляет только подходящую ветку, полностью удаляя другую ветку из программы ещё до того, как её увидит кодогенерация. Это не универсальный вычислитель времени компиляции: он существует только для выбора кода по трём встроенным константам.

```agn
struct Platform {
    write func(i64, i64, i64) -> i64
}

func linuxWrite(fd i64, buf i64, len i64) i64 {
    return 1
}

func stubWrite(fd i64, buf i64, len i64) i64 {
    return 0
}

func main() {
    var platform Platform
    comptime {
        if TARGET_OS == "linux" {
            platform.write = linuxWrite
        } else {
            platform.write = stubWrite
        }
    }
    stdio.Println(platform.write(1, 0, 4))
}
```

## Доступные константы

- `TARGET_OS`: значение `--target-os=` (`linux`, `freebsd`, `windows` или `hurd`).
- `TARGET_ARCH`: целевая архитектура (`x86_64`).
- `MEM_MODE`: значение `--mem=` (`arc`, `manual` или `orc`).

## Грамматика условия

Условие `comptime if` — это одна из этих констант, сравниваемая со строковым литералом через `==` или `!=`, в сочетании с `&&`, `||` и `!`:

```agn
comptime {
    if TARGET_OS == "linux" && MEM_MODE == "arc" {
        // ...
    }
}
```

Всё остальное в условии (переменная, вызов функции, числовое сравнение) не вычисляется на этапе компиляции и является ошибкой компиляции. Циклов comptime и вычисления функций в comptime нет; тело каждой ветки — обычный код времени выполнения, на этапе компиляции решается только то, какая ветка остаётся.
