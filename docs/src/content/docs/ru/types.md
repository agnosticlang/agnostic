## Скалярные типы

| Тип | Значение |
|---|---|
| `i64` | 64-битное знаковое целое |
| `i32` | 32-битное знаковое целое |
| `i8` | 8-битное знаковое целое |
| `u64` | 64-битное беззнаковое целое |
| `u32` | 32-битное беззнаковое целое |
| `u8` | 8-битное беззнаковое целое |
| `f64` | 64-битное число с плавающей точкой |
| `bool` | булев тип |
| `string` | строка |
| `int` | синоним `i64` |
| `float` | синоним `f64` |

Литерал с `.` (`3.14`) — это `f64`; литерал без точки (`3`) — это `i64`. Смешивание `f64` и целого
в арифметике (`3.14 + 2`) неявно приводит целочисленный операнд к `f64`, и типом выражения
становится `f64`; `%` и битовые/сдвиговые операторы не принимают операнды `f64`. `f64` работает
только под `--backend=llvm` и `--backend=gcc` — `--backend=nvm` отклоняет любое использование `f64`
на этапе компиляции, поскольку его байткодовая стековая машина целиком 32-битная целочисленная, а
интерпретатора в репозитории нет, чтобы проверить какую-либо кодировку float.

Нет и отдельного типа `char`: байт, полученный при индексации строки или через `stdio.ReadChar`, — это `int`.

## Вывод типов

`var x = expr` выводит тип `x` из `expr`. `var x int = expr` явно объявляет тип и проверяет `expr` на соответствие ему. Объявление без инициализатора (`var x int`) получает нулевое значение этого типа.

## Указатели

`&x` берёт адрес `x`. Тип указателя записывается как `*T`, а `*p` читает или записывает значение, на которое он указывает:

```agn
func set(p *int, v int) {
    *p = v
}

func main() {
    var x int = 5
    var p *int = &x
    *p = 99
    set(&x, 7)
}
```

`*[N]T` неявно приводится к `*T`, указателю на первый элемент. Так байтовый массив передаётся как буфер:

```agn
var buf [64]u8
var n Option<int> = os.ReadFd(fd, &buf, 64)
```

Указатели поддерживаются под `--backend=llvm` и `--backend=gcc`. `--backend=nvm` отклоняет `&` на этапе компиляции: обычные локальные переменные в байткоде Novaria Virtual Machine — это слоты стека, относительные к фрейму, а не адресуемая память.

## Массивы

Фиксированного размера, размер и тип элемента указываются перед тем, как переменную можно использовать:

```agn
var arr [8]int
arr[0] = 5
var first int = arr[0]
```

Размер массива — целочисленный литерал времени компиляции. Литералов массивов нет, и срезов тоже нет: каждый элемент задаётся отдельно или в цикле.

## Типы функций

Записываются как `func(T1, T2) -> R`, либо `func() -> R` без параметров, либо `func(T1)` с выводимым `void`-возвратом. См. [Функции и замыкания](/ru/functions/).

## Правила проверки типов

Типы проверяются, а не молча приводятся друг к другу там, где это потеряло бы информацию. Присваивание между целыми разной ширины допускается там, где это разрешает правило `canAssignTo` тайпчекера (знаковые и беззнаковые целочисленные виды свободно взаимно конвертируются на уровне проверки типов; сгенерированный код усекает или расширяет значение до нужной ширины). Неявного преобразования между `string` и любым числовым типом нет.

## Дженерики и сопоставление с образцом

Обобщённые *структуры*, разрешаемые на этапе компиляции монолиформизацией, существуют — см.
[Обобщённые структуры](/ru/structs/#обобщённые-структуры-дженерики). Обобщённые *функции* тоже есть, через
параметры `comptime` вместо синтаксиса `<...>` — см. [Обобщённые
функции](/ru/comptime/#обобщённые-функции). Выражения `match`/`switch` нет: ветвление — это только
`if`/`else` (см. [Управляющие конструкции](/ru/control-flow/)).
