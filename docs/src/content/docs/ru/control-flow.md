## if / else

```agn
if x > 0 {
    stdio.Println(1)
} else {
    stdio.Println(0)
}
```

Фигурные скобки обязательны. Конструкции `else if` нет: ветку `else`, начинающуюся с другого `if`, нужно оборачивать в собственный блок:

```agn
if x % 15 == 0 {
    stdio.PrintlnStr("FizzBuzz")
} else {
    if x % 3 == 0 {
        stdio.PrintlnStr("Fizz")
    } else {
        stdio.Println(x)
    }
}
```

## for

`for` покрывает все формы циклов. С условием он ведёт себя как `while`:

```agn
var i int = 0
for i < 10 {
    stdio.Println(i)
    i = i + 1
}
```

Без условия цикл бесконечен, пока не встретится `break`:

```agn
for {
    if done() {
        break
    }
}
```

`while` и `loop` принимаются как синонимы `for`; грамматика одна и та же, с условием или без. Трёхчастной C-подобной формы `for (init; cond; step)` и формы `for x in range` нет.

## break и continue

`break` выходит из ближайшего охватывающего цикла. `continue` переходит к проверке условия следующей итерации. Оба отклоняются на этапе проверки типов вне цикла, а `break` или `continue` внутри тела замыкания видят только циклы в теле самого этого замыкания, а не циклы функции, внутри которой замыкание объявлено.

```agn
var found int = 0
var n int = 2
for found < 10 {
    if math.IsPrime(n) == 0 {
        n = n + 1
        continue
    }
    stdio.Println(n)
    found = found + 1
    n = n + 1
}
```

## return

`return` без значения завершает функцию, ничего не возвращающую. `return expr` завершает её со значением; объявленный тип возврата функции и тип `expr` должны быть совместимы. Если функция доходит до конца тела без явного `return`, она возвращает нулевое значение своего типа возврата (а для `main` — завершается с кодом 0).
